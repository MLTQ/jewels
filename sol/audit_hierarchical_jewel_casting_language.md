# `audit_hierarchical_jewel_casting_language.py`

## Purpose

Runs fresh-source Gate 0d for the hierarchical phrase selected from prior diagnostics: pair-level
layout/covariance and individual-level surface/gradient. It refits both vocabularies after excluding
the three new validation sources and audits nine independent optimized fields.

## Components

### `compose_hierarchical_features` / `hierarchical_decisions`
- **Does**: Composes pair geometry with individual appearance and counts only active role decisions.

### `hierarchical_histogram` / `pairwise_hierarchical_similarity`
- **Does**: Compares the registered content-bearing token roles without the mathematically constant
  individual-layout axis.

### `main`
- **Does**: Enforces one training field per source, exactly three fits per fresh validation source,
  fits source-disjoint codebooks, renders matched residual arms and grid control, and evaluates the
  frozen quality, tilt, canonicality, irregularity, exactness, and decision-cost gate.

## Contracts

| Dependent | Expects | Breaking changes |
|---|---|---|
| Gate 0d protocol | Fresh three-source split and deterministic pair/individual fits | Data ownership |
| Future caster | Pair geometry plus individual appearance hierarchy | Active role composition |
| Scientific review | Same random points/background and independent-fit canonicality controls | Audit ownership |
