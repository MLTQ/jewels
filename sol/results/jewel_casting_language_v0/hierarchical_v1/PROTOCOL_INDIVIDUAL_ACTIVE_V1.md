# Active individual-Jewel language Gate 0f protocol

## Decision question

Does the original proposal work directly when stated without a mathematically redundant token: one
predefined Jewel description plus its continuous centroid?

Bundle-1 layout is identically zero because its anchor is the exact Jewel centroid. Gate 0c's
four-role composite cosine therefore compared two vectors dominated by the same constant layout
histogram and obscured strong meaningful-factor margins. Gate 0f removes that constant from both the
language and its accounting; it does not change any learned prototype or validation field.

## Frozen representation and fresh data

- Frozen source-disjoint Gate-0d individual K=1,024 codebook.
- The same nine fresh fields: cartoon dog park, 3D workshop, and anime ballet at fitter seeds 0/1/2.
- Each Jewel emits: coarse cell address, exact continuous centroid, covariance token, surface/opacity
  token, and color-gradient token. No layout token and no exact residual are emitted.
- Active language similarity concatenates cell-conditional covariance, surface, and gradient
  histograms only.
- Token render uses residual scale zero. Full residual remains a numerical audit arm, not part of
  the claimed representation.

## Registered gate

All checks must pass:

1. Every source Jewel is emitted; token rendering is at least 20 dB on the same support-complete
   4,096 random volume points.
2. Token median mixed spacetime tilt remains within 15% of the continuous source.
3. Active-token same-source-minus-different-source cosine margin is at least 0.05.
4. Exact cell-center locking is below 1%; full-residual numerical audit is at least 80 dB.
5. Three active role decisions per Jewel require at most 40,000 decisions for an eight-frame slice
   of the frozen 49-frame/72k-Jewel field.

A pass licenses the free-running prompt-conditioned caster. It proves a finite-vocabulary,
irregular, render-capable Jewel action language on fresh source-disjoint fields; it does not claim
codec utility or prompt generation yet.
